# Bundled fonts

Source Serif 4 comes from Adobe's source-serif release branch.
OpenDyslexic comes from `@fontsource/opendyslexic` version 5.3.0, downloaded
from unpkg.com. It includes Latin WOFF2 files in regular, bold, italic, and
bold italic, with its license alongside them.
The remaining families are Latin variable WOFF2 builds from their respective
`@fontsource-variable` packages, version 5.3.0, downloaded from unpkg.com.
Normal and italic files are included. Each family has its license alongside it.
Characters outside the bundled subsets use the browser fallback fonts.
